# Temporary Ink 功能路线图

本路线图只规划**用户可见功能**，不涉及代码实现与运行效率。所有条目都遵循 DevDoc 的产品红线：

- 零持久化：不创建批注、不修改 PDF/attachment/数据库、不进撤销历史、不参与同步；
- OFF 状态完全把交互让位给 Zotero，不拦截任何正常操作；
- 插件保持小巧，不膨胀为"第二套批注系统"。

条目状态：**v0.2**＝已于 v0.2.0（2026-08-14）实施；**v0.3**＝下一步实施的批次；**未排期**＝写入计划但暂不实施；**不做**＝维持排除。

---

## v0.2 — 现有功能打磨（✅ 已实施：v0.2.0）

### 1. 模式可见的工具栏

- **用户价值**：当前工具栏图标不随模式变化，用户无法一眼看出 PEN/RECTANGLE/OFF 状态，容易误画。
- **交互方式**：按钮图标随 OFF / PEN / RECTANGLE 三种模式切换（沿用 Zotero 原生 active 态规范），悬停 tooltip 显示当前模式。
- **验收标准**：点击切换后图标立即变化；OFF 状态图标恢复默认样式；不残留重复按钮。

### 2. 快捷调色板

- **用户价值**：换颜色目前必须进偏好面板，打断阅读流。
- **交互方式**：点击工具栏按钮右侧箭头（或长按按钮）展开 6 个预设色块，单击即切换当前笔色；数字键 1–6 快速切换；偏好面板保留精确颜色值。
- **验收标准**：换色后下一笔立即生效；色块高亮显示当前颜色；不拦截 Zotero 快捷键；选择不写入任何 Zotero 数据。

### 3. 快捷线宽调节

- **用户价值**：线宽调整与颜色一样，应该随手可调。
- **交互方式**：`[` / `]` 每次增减一档（或修饰键+滚轮）；偏好面板保留精确值（1–20 px）。
- **验收标准**：调节即时生效并显示当前宽度（可与提示徽标联动）；不影响 Zotero 原有按键行为。

### 4. 屏幕角落提示徽标

- **用户价值**：按住修饰键临时调用时，用户需要确认"当前是什么工具、什么颜色"。
- **交互方式**：按住修饰键（或处于 PEN/RECTANGLE 模式时开始拖动）在阅读器角落短暂显示工具名+颜色点，约 1 秒后或松键后消失；纯显示，不拦截任何事件。
- **验收标准**：OFF 模式按住修饰键时出现；松键消失；不留下 DOM 残留。

### 5. 中英文文案统一

- **用户价值**：术语不一致会让用户和文档都困惑。
- **范围**：核对 zh-CN / en-US locale 中"临时墨迹 / 临时画笔 / 框选 / 快捷键"等术语，并与 README、偏好面板、工具栏 tooltip 统一。
- **验收标准**：两语言同义术语一一对应；面板与 tooltip 无错别字或混用。

## v0.3 — 新增核心功能

### 6. 单笔撤销

- **用户价值**：目前 Esc 只能全清，一笔画错就得从头再来；多笔画圈点场景尤其需要。
- **交互方式**：撤销上一笔（工具栏按钮或 Alt+Z，避开 Zotero 的 Ctrl+Z）；仅操作内存中的墨迹，不触碰 Zotero 撤销历史。
- **验收标准**：撤销只移除最近一笔；正在绘制中不响应；全部撤销后按钮置灰；关 PDF 后无残留状态。

### 7. 固定（Pin）模式

- **用户价值**：有时希望墨迹多停留一会儿（阅读对照、截图前标记），但又不想要真批注。
- **交互方式**：图钉按钮或指定快捷键冻结当前全部可见墨迹——保持显示直到 Esc、滚动/缩放、或再次点击解除；关 PDF 即消失（保持零持久化）。
- **验收标准**：固定后不进入淡出；解除后按原生命周期继续；Esc/滚动/缩放清空行为不变；不产生任何 Zotero 数据。

### 8. 页坐标锚定（滚动/缩放不清除）

- **用户价值**：当前滚动、缩放、旋转、调窗口都会清空墨迹（README 已知限制），是体验上最大的短板；锚定后墨迹跟随页面移动，阅读辅助价值接近真批注。
- **交互方式**：把笔画记录从视口坐标升级为 PDF 页坐标，滚动/缩放时实时变换重绘；实现失败时"清空"保留为回退行为。
- **验收标准**：滚动后墨迹仍停在被标记的文字上；缩放/旋转后位置与粗细正确；跨页笔画、连续滚动、spread 模式行为定义清楚并记录；OFF 与原生工具互不干扰。
- **备注**：复杂度最高（zoom / rotation / spread / page gap / continuous scroll），v0.3 内最后实施，需要独立的 Zotero 源码调查记录。

### 9. 新增两个临时工具：直线、高亮笔

- **用户价值**：划掉无效段落用直线更整洁；高亮笔适合强调大段文字（宽、半透明、视觉像荧光笔）。
- **交互方式**：工具栏由单按钮循环升级为"主按钮 + 下拉菜单"（Off / Pen / Rectangle / Line / Highlighter）；直线＝起终点两点；高亮笔＝宽线宽+低不透明度，颜色可配置。
- **不做**：椭圆、箭头（DevDoc 曾排除箭头，维持排除）。
- **验收标准**：两种新工具与现有淡出生命周期一致；快捷键临时调用（修饰键组合）明确不冲突；切换工具不影响 Zotero 原生工具状态。

### 10. 绘制中临时调参

- **用户价值**：画到一半想换粗细/透明度，不想停下来进面板。
- **交互方式**：按住绘制期间滚动滚轮实时调线宽（或透明度），松开后恢复偏好默认值。
- **验收标准**：调节不打断当前笔画；新笔画使用默认值；与 Zotero 滚轮缩放不冲突（仅绘制中生效）。

## 未排期（写入计划，暂不实施）

以下方向已确认有价值，但暂不投入，待你明确点选后再立项：

1. **分屏副视图**：README 限制"仅主视图"；两个视图各挂独立画布与笔画。
2. **Snapshot 阅读器**：图片型阅读器无文字层、无 pdf.js 事件总线，overlay 逻辑可复用，适配器需新增定位路径。
3. **EPUB 阅读器**：结构完全不同（无页概念、独立滚动容器），需单独源码调查，优先级最低。
4. **截图导出 PNG**：把"当前视口画面+可见墨迹"复制到剪贴板或另存文件；只读屏幕像素、不落库、不改 PDF（DevDoc 曾排除，重新提请决策）。
5. **演示/白板模式**：整页遮罩+长时间墨迹，教学演示用（Pin 模式的加强版）。

## 不做（维持 DevDoc 边界）

真正批注、PDF/attachment/数据库修改、OCR、文本工具、云同步、笔记导出、多人协作、AI、手写识别、页级永久绘图——继续排除，除非明确重新决策。

## 发布验收（每版本前置）

补齐 `docs/manual-test.md` 中未完成项，作为每个版本发布的前置条件：

- 批注计数压力门：画 100 次笔/框，批注数不变、撤销历史无条目、无同步活动；
- Windows 显示缩放 100% / 125% / 150% / 200%；
- 多 Reader 并发独立；
- 反复禁用/启用插件无残留；
- 上述每项记录 Zotero 版本、OS、缩放、PDF、起始批注数与结果。
